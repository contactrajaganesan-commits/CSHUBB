Security

Built with security-first architecture

Your customer data is sensitive. CSHUBB is built on enterprise-grade security foundations with complete org isolation.

🔒

Row-Level Security

Supabase RLS policies enforce strict data isolation. Every query is scoped to your org — no other workspace can ever access your data.

✉️

Magic Link Auth

No passwords stored. Login is via email magic links — passwordless, phishing-resistant authentication for every user.

🎫

Invite-Only Access

New users require a valid invite code to join your workspace. Admins control who gets in and can revoke access instantly.

🔑

HMAC Webhook Signing

Webhook payloads are signed with HMAC-SHA256 so receiving systems can verify every request truly came from CSHUBB.

📋

Audit Logs

Every account operation, AI run, and admin action is logged. Admins can review the full audit trail at any time.

🧠

AI Privacy Options

Use Groq or cloud AI with your key, or run LM Studio completely offline — your data never leaves your machine.
