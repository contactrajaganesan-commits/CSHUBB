Getting Started

CSHUBB is a private, invite-only Customer Success workspace built for SaaS teams. It gives your CS team a secure hub to track account health, manage renewals, visualise revenue, monitor churn risk, and run AI-powered workflows — all in one place.

It's designed to replace the fragile combination of spreadsheets, CRM hacks, and scattered notes that most CS teams rely on, without the $30K/year cost of enterprise tools like Gainsight or Totango.

CSHUBB is currently in private beta. Access is by invitation only. To request access:

  • Visit join.cshubb.com and submit a beta request with your name, work email, company, and team size.
  • We review requests and provision your workspace within 24 hours.
  • You'll receive an email with your invite code and login instructions.

Already have a workspace? Log in at app.cshubb.com.

On your first login, enter your full name, work email, organisation name, and the invite code you received. CSHUBB sends a magic link to your email — click it, return to the browser tab, and you'll be logged in automatically.

No passwords. No lengthy setup. Your workspace is ready immediately after first login.

Go to Admin → Invite Codes and generate invite codes for your team members. Share the code (and the login URL app.cshubb.com) with each person. They follow the same first-time login flow — entering their details and the code.

The number of users you can invite depends on your plan (Trial: 3, Starter: 5, Growth: 15, Pro: 50, Enterprise: unlimited).

Most teams are fully operational within an hour of receiving access:

  • 5 min — Log in and familiarise yourself with the Accounts module
  • 15 min — Download the CSV template, populate your accounts, drag-and-drop import
  • 5 min — Set up Groq AI (free key from console.groq.com) or use it instantly
  • 10 min — Invite your team members via invite codes

No professional services, no implementation projects, no 6-week onboarding.

Accounts & Data

Go to Import / Export → download the CSV template → fill in your account data → drag and drop the file onto the import zone (or click to browse).

The CSV supports these columns: name, csm, tier, industry, region, status, health, arr, mrr, nps, usage, tickets, renewalDays, stage, expansionFlag, churnRisk, tags

All imported accounts sync instantly to all users in your org. You don't need to refresh.

Yes, on Pro and Enterprise plans. Go to Import / Export → Custom Fields tab → add a field name and type (text, number, yes/no, date, or dropdown). Custom fields appear in account records, the add/edit modal, and bulk edit — and sync to all org users immediately.

Select multiple accounts using the checkboxes in the Accounts table. A bulk action bar appears at the top. Click Edit to open the bulk edit modal — only fill in the fields you want to change (blank fields are skipped). Changes apply to all selected accounts and sync to all org users instantly.

Bulk edit is available on Starter and above. Bulk delete is an admin-only action on Pro and above.

Go to Import / Export → Export section. You can export:

  • CSV — all accounts in spreadsheet-compatible format (all plans)
  • JSON — full structured data export for backup or migration (Growth and above)

When bulk-deleting accounts (admin only), CSHUBB shows an export-first modal to ensure you always back up before deleting.

Use the search bar in the Accounts module to find any account by name, CSM, industry, or region — it filters instantly as you type.

For deeper analysis, use the 7-dimension filter bar to slice by: Tier, Status, Health, Churn Risk, Region, Industry, and CSM simultaneously. Active filters are shown as a banner so you always know what slice you're looking at.

Each account has an Activity Log where you can add timestamped notes with types: Call Summary, Risk Flag, Follow-up, QBR Note, Escalation, or General. Notes are visible to all workspace users and synced in real-time.

Access notes via the Quick Panel (click any account row → Notes tab) or from the full edit modal. Notes are stored indefinitely and ordered chronologically.

Yes. Admins can show or hide columns by clicking the ⚙ Columns button in the Accounts header. Column preferences are saved per org and apply to all team members. This keeps the table focused on the fields your team actually uses.

AI Tools

Groq is the default AI provider — it's fast, free, and runs Llama 3.1 8B at 500+ tokens/second. To use it:

  • Go to console.groq.com and create a free account
  • Generate an API key
  • Paste it in CSHUBB → AI Settings → Groq → Set as Active

Alternatively, your admin may have already set an org-wide Groq key — in which case you don't need to configure anything at all.

LM Studio lets you run AI models 100% on your own device — no internet connection required, no data leaves your machine. Setup:

  • Download LM Studio from lmstudio.ai
  • Load a model (e.g. Mistral 7B Instruct, Llama 3.1 8B)
  • Go to Local Server tab → Start Server → enable CORS
  • In CSHUBB → AI Settings → LM Studio → enter your server URL (default: http://localhost:1234) and model name
  • Click ⚡ Test Connection → Set as Active

LM Studio is available on Enterprise plan only, as it requires the user to run a local server.

Available on Pro and Enterprise plans. Get your API key from console.anthropic.com, then paste it in CSHUBB → AI Settings → Claude → Set as Active. Your key is stored only in your browser and is never sent to CSHUBB servers.

Available on Growth, Pro, and Enterprise plans. Get a free API key from aistudio.google.com. In CSHUBB → AI Settings → Gemini → paste your key and select a model (Gemini 2.5 Flash is recommended for speed and quality). Set as Active.

Supported models include: gemini-2.5-flash, gemini-2.5-flash-lite, gemini-2.5-pro, gemini-2.0-flash, gemini-1.5-pro.

Yes. Admins can set the API Key Policy to "Org-wide key" mode in AI Settings. In this mode, the admin sets one API key that all team members use — users see AI working without ever needing to configure their own key. This is the recommended setup for most teams.

Alternatively, "Individual keys" mode lets each user bring their own key and choose their own provider.

Every AI tool run is saved with a timestamp, the output, and which account(s) or context it was run on. Click History on any AI tool card to see all past runs.

Delta tracking compares the latest run against the previous one and highlights: new insights (green), removed items (red), and unchanged content (grey). This is especially useful for Weekly Digest and Churn Risk — you can immediately see what changed in your book week-over-week without reading everything from scratch.

Plans & Billing

Yes. CSHUBB is completely free during the private beta. No credit card is required at any point. All beta users get extended free access even after pricing is announced post-beta.

Plans differ in the number of users, accounts, AI runs per month, and which features are enabled:

  • Trial — 3 users, 50 accounts, 20 AI runs/mo. Accounts module, CSV import/export, notes, tags, Account Pulse AI.
  • Starter — 5 users, 200 accounts, 100 AI runs/mo. Adds Revenue, Pipeline, AI Tools module, Churn Risk AI, Weekly Digest AI, bulk edit.
  • Growth — 15 users, 1,000 accounts, 500 AI runs/mo, 3 webhooks. Adds QBR Talking Points, Expansion Spotter, Gemini AI, JSON export.
  • Pro — 50 users, 5,000 accounts, 2,000 AI runs/mo, 10 webhooks. Adds custom fields, bulk delete, Claude AI, HMAC webhook signing, org-wide key policy.
  • Enterprise — Unlimited everything. Adds LM Studio, custom integrations, dedicated onboarding, SLA.

During beta, plan changes are handled by the CSHUBB team. Email support@cshubb.com or book a call to discuss upgrading your workspace. Post-beta, self-serve plan management will be available in Admin → Plan & Billing.

Feature flags control which modules and capabilities are active for your workspace. They are set per-org based on your plan. The CSHUBB admin (not your workspace admin) can also manually override feature flags for specific orgs — for example, to grant trial access to a Growth feature during an evaluation period.

Your workspace admin can see the current feature state in Admin → Org Control. Users must refresh their browser to see navigation changes after feature flags are updated.

Integrations & Webhooks

Go to Admin → Webhooks → New Webhook. Copy the endpoint URL and secret token. Use these in your integration platform:

  • Zapier — use a Webhooks by Zapier trigger with the CSHUBB endpoint
  • Make (Integromat) — use an HTTP module as a webhook receiver
  • n8n — use a Webhook node
  • HubSpot / other CRMs — configure HTTP POST to the CSHUBB webhook URL

Webhooks support upsert, create, and update modes. HMAC signing is available on Pro+ for payload verification.

Webhook limits by plan: Trial (0), Starter (0), Growth (3), Pro (10), Enterprise (unlimited). Each webhook endpoint has its own URL and secret. Webhooks are only available on Growth plan and above.

Admin & Security

Only users with the admin role can see the Admin panel. The Admin panel includes: Users, Invite Codes, Usage Logs, Help Requests, Deletion Requests, Beta Requests, Webhooks, Org Control, and PLG Analytics.

The first user to create a workspace automatically becomes admin. Admins cannot be demoted through the UI — contact support@cshubb.com if you need to transfer admin ownership.

Go to your Profile drawer (click your name/avatar in the sidebar) → Account Actions → ⚠ Request Account Deletion. This submits a deletion request to the CSHUBB admin. Alternatively, go to Help & Feedback → Request Type → Request Account Deletion.

Deletion requests are processed within 5 business days. All your personal data and associated account records will be removed.

No. CSHUBB uses Supabase Row-Level Security (RLS) at the database level to ensure complete data isolation between workspaces. Every row in every data table is scoped to your org. It is architecturally impossible for another workspace's queries to return your data. See the Security Overview for full details.

CSHUBB collects:

  • Account data: your name, email, and org name — used to provision and manage your workspace access.
  • Product analytics: anonymised usage events (e.g. "AI tool run", "account imported") via PostHog with session recording disabled, autocapture disabled, and no PII in event payloads.
  • Support data: the content of any help requests or feedback you submit.

We do not sell, share, or monetise your data. Your customer account data belongs to you.

Troubleshooting

Check these in order:

  • API status bar at the top shows "AI offline" — this means no provider is configured or your key is invalid.
  • Go to AI Settings → verify your Groq key is entered and the Groq dot is green.
  • Make sure the correct provider is set as active (click "Set as Active").
  • For LM Studio: confirm the local server is running, CORS is enabled, and the URL/model name are correct.
  • If using an org-wide key set by your admin, the status bar should show the provider. If it still shows offline, ask your admin to re-check the key.

Common fixes:

  • Use the downloadable CSV template from Import / Export to ensure the correct column headers.
  • Column headers must exactly match the expected names (e.g. arr not ARR or Annual Revenue).
  • Health, usage, and NPS should be numbers (0–100). ARR and MRR should be numbers without currency symbols.
  • expansionFlag should be true or false. churnRisk should be Low, Medium, High, or Critical.
  • Check the feedback message below the import zone — it usually explains what went wrong.

Check your spam/junk folder first — magic link emails occasionally land there. The email comes from Supabase Auth on behalf of CSHUBB.

If you still don't see it after a few minutes, click ← Try again on the login screen and re-enter your email to request a new link. Magic links expire after a short window, so old links may be invalid.

If the problem persists, email support@cshubb.com.
